Specifications

8.2
    Specifications for functions are located in the interface file 
    with four main clauses. 
        [preconditions] (**:[]*)
        [postconditions](**:[]*)
        [raises]: dynamic typing to turn partial to total function (**Raises:[]*)
        [examples](**Example :[]*)
    in addition to comments for how the function are implemented

    specifying modules features both the 
        Abstraction function: Interprets the representation type as the data abstraction 

        Representation Invariant: Identifies meanigful value of the representation type
